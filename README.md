# Matematik Asistanı

A Streamlit app that turns your PDF lecture notes into an interactive study assistant, powered by the Gemini API.

## Features

- Browse your PDF lecture notes from the app
- Ask questions about the notes and get answers grounded in their content
- Generate practice exam questions from a selected note

## Tech stack

Python · Streamlit · PyMuPDF (fitz) · Google Generative AI (Gemini)

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Add your Gemini API key (see `app.py` for how it's loaded).
3. Put your PDF notes in the `notlar/` folder.
4. Run the app:
   ```
   streamlit run app.py
   ```
